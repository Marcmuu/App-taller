# Roadmap recomendado

## Fase 0 — Prototipo UI

Objetivo:
validar navegación y experiencia.

Construir las 15 pantallas con datos mock.

Sin Supabase todavía salvo Auth opcional.

## Fase 1 — MVP funcional

Implementar:
- Auth
- talleres
- perfiles
- vehículos
- citas
- repair_orders
- historial de estados
- presupuesto
- aceptación/rechazo
- mensajes básicos
- Storage
- Realtime

## Fase 2 — Piloto real

Añadir:
- configuración de horarios
- notificaciones email/push
- mejor gestión multimedia
- métricas básicas
- importación manual o API desde ERP si existe

## Fase 3 — Integraciones

Solo después de validar el producto:
- conexión con ERP del taller
- webhook/API
- sincronización de clientes/vehículos
- sincronización de órdenes/presupuestos
- WhatsApp/SMS

## Fase 4 — Producto maduro

Posibles extensiones:
- múltiples centros
- roles avanzados
- plantillas de comunicación
- automatizaciones
- analítica
- portal white-label

No convertir estas fases automáticamente en un ERP.
